## 1. 時刻規則

- **全部 UTC**。JST（UTC+9）は括弧内か「JST」列だけに書く。
- git の `%ad` は author date をコミッタのタイムゾーンで出すので、`+0900` と `+0000` が混ざる。素のまま `git log` を読むと順序を取り違える。実例（`git log --date=iso`、出所: 本リポジトリ）:

| 5e42f81 | 2026-10-04 13:01:34 +0900 | 2026-10-04 04:01:34 | |
| 85a0e4e | 2026-10-04 23:14:37 +0900 | **2026-10-04 14:14:37** | 素の「23:14」は 0771041 の「14:37」より後に見えるが、実際は 23 分早い |
| 0771041 | 2026-10-04 14:37:21 +0000 | 2026-10-04 14:37:21 | +0000 |
| 88d1bc0 | 2026-10-04 14:49:27 +0000 | 2026-10-04 14:49:27 | +0000 |

- Workflow の journal.jsonl には時刻が無い。Workflow の時刻は、起動 = `workflows/scripts/*-<wf ID>.js` の mtime、各担当の開始・終了 = `agent-*.jsonl` の timestamp から取る。
- ファイルの mtime は「最後に更新された時刻」で、作成時刻ではない。第 5 節はこの前提で読む。
- メイン会話の transcript は 2026-10-04 14:26:31 UTC に始まる。それ以前（10-03 の調査・設計、10-04 04:01 の一括コミットまで）の会話記録は手元に無く、**ユーザーが何をいつ言ったかは不明**。
